● En producción

ComoVivo

Finanzas personales y de pareja · App web instalable

App para ordenar la plata del mes en Argentina, solo o de a dos: sueldos, gastos fijos, tarjetas con cuotas y ahorros. Responde lo que todos se preguntan a mitad de mes: cuánto me queda por día y quién le debe a quién.

Tecnologías

  • Spring Boot 4
  • Spring Security + JWT
  • Spring Data JPA
  • PostgreSQL
  • Flyway
  • API REST
  • React 19
  • TypeScript
  • Vite
  • Tailwind CSS
  • TanStack Query
  • PWA
  • JUnit 5 + Mockito
  • Vitest
  • Docker
  • Render + Neon
Probar la app

El código es privado. Lo muestro con gusto en una entrevista.

Qué hace

  • Cuánto te queda por día hasta fin de mes, descontando fijos, cuotas que vencen y lo que apartaste para ahorrar.
  • Tarjetas con cierre y vencimiento: cada compra en cuotas cae en el resumen que corresponde, con vista previa al cargarla.
  • Gastos en pareja: reparto igual, proporcional al sueldo o por categoría; saldo acumulado entre los dos y transferencias para saldar.
  • Ahorros y metas en pesos y dólares, con cotización del día y cuánto poner por mes para llegar.
  • Se instala en el celular (PWA) y deja cargar gastos sin señal: se suben solos al volver la conexión, sin duplicarse.
  • Seguridad: registro con email confirmado, JWT con refresh tokens rotativos y privacidad de los gastos personales dentro de la pareja.
  • En producción con Docker en Render y PostgreSQL en Neon; 76 tests automáticos con JUnit 5, Mockito y Vitest.

Tienda online · Cliente real

E-commerce para un emprendimiento de decoración y accesorios hechos a mano. La dueña carga productos, arma ofertas y gestiona pedidos desde su celular, sin depender de un programador.

Proyecto de un cliente: el código es privado. Lo muestro con gusto en una entrevista.

Qué hace

Consultorio Odontológico

Sistema de gestión · SaaS multi-consultorio

Sistema web para odontólogos y secretarias: pacientes, turnos, obras sociales e historia clínica con odontograma digital. Nació con Servlets y JSP y lo migré a Spring Boot para que varios consultorios lo usen, cada uno con sus propios datos.

Tecnologías

  • Java 17
  • Spring Boot
  • Spring Security
  • Spring Data JPA
  • Thymeleaf
  • PostgreSQL
  • Flyway
  • Docker

El código es privado. Lo muestro con gusto en una entrevista.

Qué hace

  • Multi-consultorio: cada clínica ve solo sus datos; el filtro se aplica en cada consulta.
  • Roles jerárquicos: Administrador, Odontólogo y Secretaria, con contraseñas cifradas (BCrypt).
  • Odontograma digital con notación FDI y colores según las normas de las obras sociales argentinas.
  • Ficha imprimible para obra social, fotos clínicas por paciente y agenda de turnos.
  • Migración de una versión anterior en Servlets/JSP a Spring Boot.
  • Listo para producción: Docker Compose con PostgreSQL, HTTPS automático y backups diarios.
